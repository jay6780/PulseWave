## 📱 About PulseWave

**PulseWave** is a sleek, lightweight Android music application designed to give you a seamless listening experience. Featuring a clean dark-mode interface, real-time lyrics tracking, offline downloads, and smooth navigation, it brings your favorite tracks, artists, and playlists right to your fingertips.

---

## ✨ Features

* **🏠 Home Feed:** Discover top artists, trending tracks, and personalized recommendations at a glance.
* **🔍 Instant Search:** Easily find your favorite songs, albums, and artists.
* **🎶 Tracklists & Albums:** Browse complete artist discographies and curated song lists.
* **📜 Live Lyrics:** View synchronized lyrics dynamically while playing your favorite tracks.
* **⬇️ Offline Downloads:** Download tracks directly to your device to listen anytime, anywhere without an internet connection.
* **⭐ Favorites Management:** Quickly add and access your go-to tracks with a single tap.
* **🎨 Modern UI:** Built with a polished dark-themed interface, custom navigation bar, and vibrant neon audio accents.

## 📦 Getting Started

To run or build this project locally from source:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jay6780/PulseWave.git
   ```
2. **Open in Android Studio:**
   * Launch Android Studio and select **Open**.
   * Navigate to the cloned `PulseWave` folder and click **OK**.
3. **Build & Run:**
   * Sync your project with Gradle files.
   * Connect an Android device or start an emulator, then click the **Run ('▶')** button.
